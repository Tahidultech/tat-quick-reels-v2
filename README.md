# TAT Quick Reels V2

This project preserves the original TAT Quick Reels Media, Motion, Overlay and Text tabs. The Download tab now embeds the downloader implementation from TAT Downloader FB OK inside the existing tab. Download history is retained, and completed video downloads are added to the Media tab list.

Build with Code On The Go using :app:assembleDebug. The bundled yt-dlp/FFmpeg binaries target arm64-v8a.
